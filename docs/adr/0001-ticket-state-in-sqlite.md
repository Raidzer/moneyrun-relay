# Хранить карточки и позицию чтения одной транзакцией

Учёт первого ответа согласован 15.10.2026. Рабочие карточки тикетов, позиция чтения и неподтверждённая отправка хранятся в одном файле SQLite в подключённой папке данных. Разделение карточек в БД и позиции в прежнем JSON оставило бы окно сбоя: `resolve sent` мог бы продвинуть позицию без сохранения ожидающего тикета. SQLite убирает это окно без отдельного сервера и новой Python-зависимости. Прежний JSON сохраняется для проверки старой неподтверждённой отправки при переходе и для изолированных тестовых запусков; после перехода он не является актуальным рабочим состоянием. Откат к прежнему формату требует резервной копии папки данных, а не только старого образа.
